# @longtable/kpp-cli

The `kpp` command-line interface for evidence-bound Korean public proposal generation.

```sh
npx @longtable/kpp-cli --help
```

The CLI manages the source-to-release workflow: ingest, requirement confirmation, evidence/page planning, authoring exchange, deterministic build/render/audit, human approval, and release. The tool never turns a technical pass into an automatic submission; issuer-specific requirements and human approval remain mandatory.
