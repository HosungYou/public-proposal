# Korean public-document grammar

## Precedence

Use issuer-specified paper size, margins, fonts, section order, page limits, cover fields, and annexes first. Apply these defaults only where the issuer is silent.

## Default A4 system

- Portrait 210 x 297 mm.
- Margins: top 14 mm, bottom 14 mm, left 18 mm, right 18 mm.
- Header/footer distance: 9 mm.
- Ordinary analytical pages: Noto Sans CJK KR for headings/navigation and Noto Serif CJK KR for body prose. Official forms retain their prescribed font. Resolve licensed static fonts before drafting and fail font QA on silent substitution.
- Ink `#161B22`; navy `#17324D`; muted `#4D555D`; header fill `#E8EDF1`; note fill `#F3F5F6`.

| Role | Size | Rhythm |
|---|---:|---|
| Cover title | 24-28 pt bold | 1.0 lines; 10 pt after |
| Page title | 20.5 pt bold | 1.12 lines; -0.045 em |
| Section | 12 pt bold | 1.22 lines; 5 mm before, 2 mm after |
| Subsection | 9.2 pt bold | 1.25 lines; 3.5 mm before, 1.4 mm after |
| Body | 9.3 pt | 1.52 lines; -0.004 em; 2.3 mm after |
| Table | 7.9 pt | 1.32 lines |
| Caption | 8.5 pt | 1.3 lines |
| Source/note | 7.2 pt | 1.35 lines |

## Hierarchy and page use

- Use `Ⅰ. -> 1. -> 가. -> 1) -> ①`.
- Start a new page for a top-level chapter, not for every subsection.
- Default to one text column. Let full-width tables and figures occupy the column.
- Use roughly 65-82% of the printable area on ordinary pages. Merge thin sections instead of leaving a large empty lower half.
- Put an evaluator question, direct answer, and evidence IDs in a restrained navigation row when useful.
- Avoid English all-cap kickers, rounded cards, gradients, decorative metric strips, and repeated five-box layouts.

## Cover and chapter opener

- Cover: document type and notice number at top; project title in the center; consortium, representative, and date at bottom.
- Use only a real analytical line structure from the proposal as the optional lower-third visual.
- Do not use generated landscapes, people, ecosystems, invented logos, or decorative network lines.
- Chapter opener: chapter number, title, one-sentence conclusion, and linked evaluation criteria. Do not create a separate image page.

## Source and claim discipline

- Cite the latest authoritative source and a stable locator.
- Distinguish verified fact, bounded design, pending evidence, and blocker.
- Do not repeat a generic method, role table, or review gate across chapters.
- Derive summary and presentation claims only from the approved proposal.

## Visual-source grounding

- Inspect actual rendered pages. Do not infer a visual grammar from a document title, filename, search snippet, or extracted text alone.
- Use an issuer page first. Add at least one Korean official proposal-writing/template page and one Korean public research/report page when the issuer is visually silent.
- Extract spacing, hierarchy, table geometry, caption placement, density, numbering, and grayscale behavior. Do not copy branding, prose, diagrams, or decorative identity.
- Keep `mandated`, `recurring`, `preference`, and `not_transferable` observations separate.
- A large blank area is not automatically public-sector restraint. On ordinary pages it must support a deliberate reading transition; otherwise complete or merge the page.
