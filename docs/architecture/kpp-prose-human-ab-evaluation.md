# KPP prose human A/B evaluation

Date: 2026-08-25

## Instructions

For each pair, choose `A`, `B`, or `동률`. Judge the text as if it appeared in the named public document. Do not try to identify which version is newer.

Use five criteria:

1. directness: the reader can identify the answer or operating rule quickly;
2. public-sector fit: restrained, accountable, and free of sales rhetoric;
3. evidence traceability: facts, qualifications, and responsibility boundaries remain visible;
4. reading rhythm: sentences and bullets carry one material thought without becoming mechanical;
5. information sufficiency: compression does not remove necessary reasoning.

Record one overall choice per pair. Add a short reason only when useful.
