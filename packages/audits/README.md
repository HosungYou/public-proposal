# @longtable/kpp-audits

Technical audit gates for Korean public proposal artifacts.

The content audit blocks unresolved placeholders, unsupported terms, vague promises, repeated cross-page prose, and mechanical scaffold text such as `본문 작성 메모`. It also reports materially thin body blocks as warnings. These technical findings do not replace Korean editorial review or human submission approval.

The audits inspect DOCX OOXML geometry, PDF/page rendering, typography, receipt lineage, semantic figures, and DOCX embedded media. A passing technical audit is not a substitute for the issuing institution's RFP, eligibility evidence, or human submission approval.
